# Cute Apology Website 💌

A heartfelt apology website template reconstructed and restored from CutiePage, personalized from **Gugu** to **Saibun**.

## Features

- **Cover Magazine Screen:** "TO MY SAIBUN ✦" with "I'm so so so SORRY" and animated intro sticker.
- **Tic-Tac-Love Game:** Interactive 3x3 game where Saibun places the missing heart, triggering celebration animations and auto-advancing.
- **Love Letter:** Styled apology note with pinned memory photo and vintage grain "LOVE STAMPED" wax seal.
- **Photo Cards Gallery:** Interactive polaroid carousel with 3 special memory cards, captions, and signatures.
- **Dedicated Playlist:** Custom audio player with scrubber, timestamps, play/pause controls, animated equalizer bars, and original soundtrack tracks.
- **Thank You Finale:** Floating sparkle particles, closing message, sticker, and a floating mini audio widget.

## Quick Start (Run Locally)

1. Clone the repository:
   ```bash
   git clone <repo-url>
   cd cute-apology-website
   ```

2. Run directly in your browser:
   Open `index.html` in any modern web browser.

3. Or run with the local Node.js server:
   ```bash
   npm start
   ```
   Then open `http://localhost:3000` in your browser.

## Customization

The source code is organized in `src/`:
- `src/CuteApology.jsx`: All screen components, animations, and audio player.
- `src/index.jsx`: React root mounting and query parameter support.

To rebuild the bundle after making code changes:
```bash
npm run build
```
